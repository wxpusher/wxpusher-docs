# WxPusher 消息过滤更新：开发者预置关键字

消息过滤这次有三处变化：开发者可以给应用和主题预置一组关键字；订阅用户设置过滤时，点一下就能选上这些词；过滤时会同时匹配消息摘要和正文，不再区分大小写。

以前订阅用户要自己手写关键字，常常写错、写漏，开发者也没法告诉用户该填什么。现在开发者把消息里一定会出现的词列出来，用户直接勾选即可。

## 开发者：给应用和主题预置关键字

在管理后台 **[【应用管理 → 应用信息】](https://wxpusher.zjiecode.com/admin/main/app/appInfo)** 的「消息过滤」里，点「设置」就能编辑应用的预置关键字。主题的关键字在「主题管理」里单独设置，和应用的互不继承。App 里的开发者管理页面也能设置，规则一样。

![应用信息页的消息过滤设置](imgs/filter-keywords-admin-row.png ':size=600')

弹窗里可以一个个添加，也可以批量粘贴，换行、空格、逗号、顿号都能分隔。重复的词和长度不对的词，添加时就会提示。右上角显示已用的个数和字数。

![预置过滤关键字弹窗](imgs/filter-keywords-admin-dialog.png ':size=500')

填写时注意三点：

- 只填消息摘要或正文里一定会出现的词，比如消息分类、币种名。填了不会出现的词，选「仅接收」的用户会收不到消息。
- 修改或删除关键字，不影响已经选过它的用户，他们保存的关键字继续生效。
- 设置关键字本身不会过滤任何消息，用户自己开启过滤后才生效。

## 订阅用户：点选关键字过滤消息

入口是 App「我的订阅 → 订阅详情 → 设置过滤关键字」。先选过滤模式（仅接收或拒绝接收），再点选开发者提供的关键字，可以多选。开发者没提供的词，在「其他关键字」里自己填。

![App 设置过滤关键字页面](imgs/filter-keywords-user-main.png ':size=320')

自己填的词如果已经存在，会马上提示。和开发者提供的词重复时（不区分大小写），点「直接选中」就行，不用再写一遍。

![自己填的词和开发者提供的重复时的提示](imgs/filter-keywords-user-duplicate.png ':size=360')

关键字超过 6 个时，顶部会出现搜索框。开发者提供的和自己填的一起搜，匹配的字会标出来。

![搜索关键字](imgs/filter-keywords-user-search.png ':size=360')

格式不对的词（少于 2 个字、包含空格或逗号）会在输入框下面直接提示，不用等到保存。右上角显示已用字数，到了上限就不能再勾选。

## 匹配规则：摘要和正文都匹配，不区分大小写

新规则会同时匹配消息摘要和正文里显示出来的文字，不区分大小写。比如关键字「cpu」，能匹配摘要里的「CPU 使用率 95%」。正文是 HTML 时，只看显示出来的字，标签和属性不参与匹配。

| | 旧规则 | 新规则 |
| --- | --- | --- |
| 匹配范围 | 只匹配正文原文 | 摘要 + 正文显示的文字 |
| 大小写 | 区分 | 不区分 |

新规则于 2026 年 11 月 1 日 21:03（北京时间）上线。切换不是到点统一生效，而是按订阅单独升级：这之后新设置或重新保存过过滤的订阅，按新规则匹配；在这之前设置过、之后没再保存的，继续按旧规则匹配，过滤效果不会突然变化。他们打开设置页时会看到提示，重新保存一次就升级到新规则。

![旧规则用户看到的提示](imgs/filter-keywords-user-legacy.png ':size=360')

## 数量和长度限制

| | 开发者预置（应用、主题各一份） | 订阅用户的关键字 |
| --- | --- | --- |
| 个数 | 最多 500 个 | 不限 |
| 单个长度 | 2–20 个字 | 至少 2 个字 |
| 总长度（含分隔逗号） | 5000 字 | 1500 字 |
| 不能包含 | 空格、逗号 | 空格、逗号 |

字数按实际字符算，一个汉字、一个字母、一个表情都算 1 个字。总长度是把所有关键字用逗号连起来的长度，比如「告警,生产环境」算 7 个字。

## 常见问题

**设置了预置关键字，用户会自动开启过滤吗？**

不会。用户自己选择过滤模式并保存后才生效，没设置过滤的用户照常接收。

**消息被用户过滤了，发送接口会怎么返回？**

按 UID 发送时，被过滤的用户对应的结果会提示「因为用户设置的关键字过滤，不发送」，可以据此区分是用户自己过滤掉的，不是发送故障。

**发给主题的消息，用的是哪一组关键字？**

主题自己的。应用和主题的预置关键字各自独立，用户订阅了哪个，就看到哪个的关键字。
