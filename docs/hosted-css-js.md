# 托管 CSS / JS

HTML 和 Markdown 消息想用自己的样式或交互脚本，可以把 CSS / JS 托管在 WxPusher。代码提交后先过 AI 审核，通过后复制引用代码贴进消息正文就能用，不用自己找地方放文件。

> 出于安全考虑，消息正文里直接写的 `<script>` 会在发送时被删掉，只有托管并审核通过的 JS 才能在消息里执行。

## 怎么用

1. 打开电脑端管理后台 **[【消息管理 → 代码托管】](https://wxpusher.zjiecode.com/admin/main/message/hosted)**，点「新建托管资源」，填写名称，选择 CSS 或 JS，粘贴代码或选择本地文件，提交审核。
2. 提交后页面会等待 AI 审核结果，通常几秒到几十秒。超过 60 秒会提示「审核中，请稍后查看审核结果」，可以稍后在列表里查看。
3. 审核通过（初审通过）后，资源变为「已上线」，点「复制引用代码」，贴进 HTML 或 Markdown 消息的正文：

```html
<link rel="stylesheet" href="https://static.zjiecode.com/wxpusher/hosted/ha_xxxxxxxxxxxxxxxx.css">
<script src="https://static.zjiecode.com/wxpusher/hosted/ha_yyyyyyyyyyyyyyyy.js"></script>
```

发送时 WxPusher 会校验每个引用，把它们统一放到消息正文末尾（先 CSS，后 JS）。手机 App 里只能查看说明，管理功能只在电脑端提供。

## 审核规则

因为托管的 JS 会在消息详情页里直接执行，审核从严。以下代码提交后会直接判为不通过：

| 类型 | 不允许 |
|---|---|
| 混淆、压缩 | 混淆过的代码（如大量 `_0x1234` 标识符、长串编码、`eval(function(p,a,c,k,e…`）；单行超过 1000 个字符且几乎没有空白的压缩代码。请提交可读的源码 |
| 动态执行 | `eval(`、`new Function(`、`setTimeout` / `setInterval` 传字符串、`String.fromCharCode` 一次拼 20 个以上字符 |
| 敏感接口 | App 原生桥（`window.wxpusher`、`webkit.messageHandlers`、`wxPusherApi`）、`document.cookie`、`localStorage`、`sessionStorage`、`indexedDB` |
| CSS | `@import`、`expression(`、`behavior:`、`-moz-binding`、`url(javascript:…)` |
| 其他 | 加载外部脚本、把页面内容或用户信息发到外部、伪造登录或支付界面、挖矿、强制跳转、违法违规内容 |

上面前四类是固定规则，编辑代码时页面会实时提示；最后一类由 AI 判断。AI 拿不准时会转给站长人工复审。

## 修改代码

- 修改代码就是提交一个新版本，同样要审核。**新版本审核通过前，线上继续使用当前版本**；通过后自动覆盖，链接不变，已经发出的消息也会使用新版本（CDN 缓存最多 10 分钟）。
- 新版本不通过时，线上版本不受影响。详情里能看到不通过的原因，修改后可以再次提交。
- 每个版本都按完整代码审核，不只看改动的部分。

## 状态说明

| 资源状态 | 含义 | 消息里能不能引用 |
|---|---|---|
| 未上线 | 还没有版本通过审核 | 不能 |
| 已上线 | 有审核通过的线上版本 | 能 |
| 已冻结 | 站长临时处置，文件已删除，可以恢复 | 不能 |
| 已下架 | 站长永久处置，不能恢复，也不能再提交 | 不能 |
| 已删除 | 你删除了这个资源 | 不能 |

| 版本审核状态 | 含义 |
|---|---|
| 审核中 | AI 正在审核 |
| 初审通过 | AI 判定通过，已成为线上版本 |
| 初审不通过 | 固定规则命中或 AI 判定违规；AI 判定的可以申诉一次 |
| 待人工复审 | AI 拿不准，或者你提出了申诉，等站长处理 |
| 复审通过 / 复审不通过 | 站长的处理结果；复审不通过不能再申诉 |
| 已作废 | 待人工复审期间你又提交了新版本，这一版不再处理 |

## 限制

- 单个文件最大 100 KB（按 UTF-8 字节计算）。
- 每个账号每天最多提交 20 次（不通过的也算），最多 50 个资源（已删除、已下架的不算），同一时间只能有 1 个版本在审核。
- 一条消息最多引用 5 个托管资源。
- 只有标准推送 `/api/send/message` 和管理后台发送消息支持引用；文本类型（`contentType=1`）的消息不处理；万能发送接口不支持。

## 常见问题

**为什么被判为混淆？** 规则会把大量 `_0x` 开头的变量、很长的十六进制或 Base64 串、连续的 `\x` / `\u` 转义当作混淆。请提交打包前的源码，长数据放到消息正文里或拆开写。

**发送时提示「托管资源 ha_xxx 不存在、未上线、已冻结或不属于当前应用」？** 引用的资源必须是你自己账号下、状态为「已上线」的资源，而且 `<script>` 只能引用 JS、`<link>` 只能引用 CSS。

**已经发出的消息里，引用为什么失效了？** 资源被删除、冻结或下架后，文件会从 CDN 删除，已发消息里的引用最晚 10 分钟后失效。
